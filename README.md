# 🎬 WatchListic

**WatchListic** is a movie discovery website designed to help users explore movies based on different categories, such as popular, now playing, upcoming, and top rated movies.

The website uses the **TMDB API** to fetch movie data and provides a simple, clean, and aesthetic interface for discovering movies.

## ✨ Features

* 🔥 Popular Movies
* 🎬 Now Playing Movies
* 🆕 Upcoming Movies
* ⭐ Top Rated Movies
* 🔎 Search Movies
* ❤️ Favorite Movies
* 🎥 Movie Details
* 📱 Responsive Design

## 🛠️ Built With

* **React.js**
* **HTML**
* **CSS**
* **TMDB API**

## 🎯 Purpose

WatchListic was created as a project to practice building a modern web application using **React.js**, integrating an external API, managing application state, and creating a clean and responsive user interface.

> Discover movies. Find your next watch. 🎬

### ❤️ Favorites

Users can add movies to their Favorites by clicking the favorite button on a movie card or movie details page.

* Add or remove movies from Favorites
* Prevent duplicate movies
* Favorites persist using `localStorage`
* Favorites remain available after refreshing or reopening the browser
* Display an empty state when no movies have been added
